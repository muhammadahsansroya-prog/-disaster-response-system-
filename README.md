# 🚨 Disaster Response & Relief Coordination System

A full-stack Web-based Disaster Response Platform built with **Django** and **Leaflet.js**, designed to bridge the gap between affected citizens, dispatch teams, and emergency responders during critical situations.

---

## 🌟 Key Features

- **Public Emergency Request Form:** Instant incident reporting with automated geolocation detection and urgency tagging (Critical, High, Medium).
- **Interactive Live Map:** Real-time marker mapping using Leaflet.js and CartoDB Voyager tiles for clear visualization of emergency sites.
- **Role-Based Access Control:** Dedicated dashboards for Dispatchers and Emergency Responders.
- **Dynamic Status Updates:** Real-time lifecycle tracking of requests (`Pending` ➔ `Dispatched` ➔ `In Progress` ➔ `Resolved`).
- **Clean UI/UX:** Responsive interfaces built with modern Bootstrap 5 components.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django 6.x
- **Frontend:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5
- **Mapping Engine:** Leaflet.js with CartoDB Tile Server
- **Database:** SQLite (Development) / PostgreSQL-ready
- **Version Control:** Git & GitHub
